# dark-mode-icecream-shop
This project is an interactive e-commerce landing page for a fictional high end gelato brand called Beosas · Midnight Gelato Speakeasy. Rather than going with a typical bright, pastel "ice cream parlor" aesthetic, the design takes a dramatically different angle: a dark, candle lit, late night speakeasy.

## Features
* Interactive shopping cart with live updates
* Smooth scrolling and GSAP powered animations
* Responsive design for desktop 
* Elegant dark-themed luxury UI
* Semantic HTML and accessible layout

## Tech Stack
* HTML5
* CSS3
* JavaScript

Designed and developed as a frontend concept project.
